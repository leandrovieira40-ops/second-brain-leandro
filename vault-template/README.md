# Second Brain — Vault

Este repositório contém **somente conhecimento**: notas em Markdown com frontmatter YAML,
compatíveis com o Obsidian. Ele é a fonte canônica; a aplicação web e seus índices são derivados.

| Pasta | Uso |
| --- | --- |
| `00-Inbox` | Capturas ainda não processadas (qualquer coisa, sem classificar) |
| `01-Fleeting-Notes` | Pensamentos curtos aguardando desenvolvimento |
| `02-Sources/*` | Notas de fonte: livros, artigos, sites, newsletters, papers, vídeos, podcasts, cursos |
| `03-Permanent-Notes` | Ideias próprias, desenvolvidas e conectadas |
| `04-Concepts` | Definições de conceitos (um conceito por nota) |
| `05-Projects` | Projetos com objetivos, decisões, experimentos e lições |
| `06-Areas` | Áreas de responsabilidade contínua |
| `07-Maps-of-Content` | Índices temáticos que organizam outras notas |
| `08-Daily-Notes` | Notas diárias |
| `09-Reviews` | Revisões periódicas |
| `10-Templates` | Modelos de nota (placeholders do plugin Templates do Obsidian) |
| `Attachments` | Imagens e anexos pequenos |
| `.second-brain/` | Decisões da aplicação que não são deriváveis (ex.: sugestões aceitas/rejeitadas) |

A organização é livre: renomeie ou crie pastas quando quiser. O tipo de cada nota vem do campo
`type` do frontmatter, não da pasta.
